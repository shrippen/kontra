## Zwei Töne pro Schlag
Eine [[achtel|Achtelnote]] dauert einen halben Schlag. Acht davon füllen einen 4/4-[[takt|Takt]]. Achtel sind der
Motor vieler Rock- und Popsongs: gleichmäßig, ohne Lücke.
::: listen root=E steps="0 0 0 0 0 0 0 0"

## Gleichmäßig bleiben
Die Achtel auf dem „und“ sind genauso lang und genauso laut wie die auf der Zahl. Wird es schneller, bleibt der
Abstand gleich; nur das Tempo steigt.
::: variant for=e-bass
Wechselschlag hilft: Zeigefinger auf der Zahl, Mittelfinger auf dem „und“, oder umgekehrt.
:::

## Üben
Achtel auf dem tiefen E zum Schlagzeug.
