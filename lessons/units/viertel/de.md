# Viertel im Takt
id: viertel
for: any
terms: takt viertel bpm metronom

## Zählen
Die meisten Lieder stehen in einem [[takt|Takt]] mit vier Schlägen: 1 2 3 4, 1 2 3 4. Eine
[[viertel|Viertelnote]] dauert genau einen Schlag. Wie schnell die Schläge kommen, sagt das Tempo in [[bpm|BPM]]:
Schläge pro Minute.
::: listen root=E steps="0 0 0 0"

## Mitzählen und spielen
Zähl laut mit und spiel auf jede Zahl einen Ton. Ein [[metronom|Metronom]] oder das Schlagzeug gibt die Schläge vor;
dein Ton soll genau mit dem Schlag kommen, nicht davor und nicht danach.
::: hint
In den ersten Übungen zählt nur, wann du anschlägst. Welcher Ton klingt, ist egal.
:::

## Üben
Viertel auf der leeren E-Saite zum Schlagzeug, erst langsam.
::: practice bundled=1 speeds="70 85 100"
