# Hearing intervals
id: intervalle-hoeren
for: any
needs: quarte-quinte septime

## Hear first, then play
If you hear an interval and know its name, you can play bass lines by ear. Listen to the examples and sing the second
note quietly before you play it.
::: hint
Tunes you know help some people as reminders, others not. What counts is listening often.
:::

## Play it back
Kontra plays a note and an interval above it. Play both back; any octave counts.
::: listen root=D steps="0 7"
::: try root=D steps="0 7" octave=any
::: listen root=G steps="0 4"
::: try root=G steps="0 4" octave=any
::: listen root=A steps="0 10"
::: try root=A steps="0 10" octave=any
