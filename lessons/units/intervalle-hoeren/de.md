# Intervalle hören
id: intervalle-hoeren
for: any
needs: quarte-quinte septime

## Erst hören, dann spielen
Wer ein Intervall hört und weiß, wie es heißt, kann Basslinien nach Gehör nachspielen. Hör dir die Beispiele an und
sing den zweiten Ton leise mit, bevor du ihn spielst.
::: hint
Merkhilfen aus bekannten Melodien helfen manchen, anderen nicht. Was zählt, ist oft hören.
:::

## Nachspielen
Kontra spielt einen Ton und ein Intervall darüber. Spiel beide nach; jede Oktave zählt.
::: listen root=D steps="0 7"
::: try root=D steps="0 7" octave=any
::: listen root=G steps="0 4"
::: try root=G steps="0 4" octave=any
::: listen root=A steps="0 10"
::: try root=A steps="0 10" octave=any

## Weiter üben
Mehr Runden mit zufälligen Intervallen gibt es auf der Seite „Gehör“ unter „Intervall“.
