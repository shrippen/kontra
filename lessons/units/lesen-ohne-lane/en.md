# Reading without the lane
id: lesen-ohne-lane
for: any
needs: vorzeichen-lesen

## Only the notes
So far the lane showed you when each note comes. Now you read from the notes alone. Set the view to "Notation"
and play slowly; speed comes with time.
::: hint
Look one bar ahead. Reading only the note that sounds now makes you late.
:::

## Practise
C major a little faster, from the notes only.
::: practice bundled=13 speeds="60 80 100"

## Check
::: question
Where is it best to look while reading?
- [ ] at the note that sounds now
- [x] one bar ahead
- [ ] at the fretboard
:::
