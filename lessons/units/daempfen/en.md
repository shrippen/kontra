# Muting strings
id: daempfen
for: e-bass
needs: saitenwechsel

## Only one note rings
Bass strings ring for a long time. [[daempfen|Muting]] means: touch what should not sound lightly, without pressing.
Both hands help:
- The fretting hand relaxes after the note but stays on the string: the note stops.
- The plucking hand rests the thumb and free fingers on the strings not in use.
- Open strings are stopped with a finger of either hand.

## Make rests heard
A rest only sounds if the note before it really stops. Listen closely: if something hums on, mute earlier.
::: hint
Over a cable Kontra hears whether a note stops before the rest: the summary counts how many notes were muted in time
and which rang into the rest. Not over a microphone yet; there a recording helps.
:::

## Practise
A groove with rests over a minor cadence in Em: every rest should be silent.
::: practice bundled=12 speeds="60 80 100"

Then staccato: every note is an eighth, followed by an eighth rest. Relax the fretting hand after each note.
::: practice bundled=151 speeds="60 75 90"

## Check
::: question
How does the fretting hand stop a fretted note?
- [x] It relaxes but stays on the string.
- [ ] It pulls the finger away quickly.
- [ ] It presses harder.
:::
