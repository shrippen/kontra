# Note values and rests
id: notenwerte
for: any
needs: viertel
terms: notenwert pause

## How long a note lasts
The [[notenwert|note value]] says how long a note sounds, counted in beats:
- Whole note: four beats.
- Half note: two beats.
- Quarter note: one beat.
- Eighth note: half a beat.
::: listen root=E steps="0 0 0"

## Rests count too
A [[pause|rest]] is a note value without a note: you keep counting but do not play. Every note has a rest of the same
length. Rests are part of the groove, not a hole in it.
::: hint
The note should really stop in the rest.
:::
::: variant for=strings
To stop it, rest a finger lightly on the string, also on an open one.
:::
::: variant for=keys
To stop it, let go of the key.
:::

## Practise
A groove with rests on the low E. Only when you pluck counts here, not which note.
::: practice bundled=46 speeds="70 85 100"
