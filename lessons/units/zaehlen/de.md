# Zählen

## Eins und zwei und
Jeder Schlag ist eine [[zaehlzeit|Zählzeit]]: 1 2 3 4. Dazwischen liegt das „und“: 1 und 2 und 3 und 4 und. So hat
jeder halbe Schlag einen Namen, und du weißt immer, wo du im Takt bist.
::: listen root=A steps="0 0 0 0 0 0 0 0"

## Laut zählen
Zähl beim Üben laut oder leise mit, auch wenn es sich anfangs komisch anfühlt. Wer zählt, verliert den Takt nicht,
wenn ein Fehler passiert: Er steigt bei der nächsten Eins wieder ein.
::: hint
Fehler sind normal. Wichtig ist, dass du nicht anhältst, sondern beim nächsten Schlag weiterspielst.
:::

## Üben
Achtel auf der leeren A-Saite: auf jede Zahl und auf jedes „und“ ein Ton. Hier zählt nur, wann du anschlägst.
::: practice bundled=52 speeds="70 85 100"
