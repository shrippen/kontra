## Slide instead of fretting again
In a [[slide|slide]] you pluck a note and slide with the same finger to the next one without plucking again. The finger
stays on the string with the same pressure. The notes in between sound briefly.
::: figure root=A steps="0 2" labels="1 2" string=E
::: variant for=e-bass
Slide on the E string from the fifth to the seventh fret.
:::

## Try it
Play A, then slide to B.
::: try root=A steps="0 2" string=E

## Check
::: question
How often do you pluck in a slide?
- [x] once, at the start
- [ ] again for every note
- [ ] not at all
:::
