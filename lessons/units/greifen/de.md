# Greifen ohne Kraft
id: greifen
for: strings
needs: bass-teile
terms: bund

## Ein Finger pro Bund
Die Greifhand steht so, dass jeder Finger einen eigenen Bund hat: Zeigefinger 1, Mittelfinger 2, Ringfinger 3,
kleiner Finger 4. Der Daumen liegt hinter dem Hals, etwa hinter dem Mittelfinger.
::: figure root=A steps="2 3 4 5" labels="1 2 3 4" string=A
::: variant for=fretted
Die Fingerkuppe drückt direkt hinter dem [[bund|Bund]], nicht darauf und nicht in der Mitte zwischen zwei Bünden.
:::
::: variant for=fretless
Ohne Bünde greifst du genau auf der Linie, wo der Bund wäre; dein Ohr entscheidet, ob der Ton stimmt.
:::

## Nur so fest wie nötig
Drück nur so fest, dass der Ton sauber klingt. Probier es aus: erst ganz leicht (es schnarrt), dann etwas fester, bis
der Ton klar ist. Mehr Kraft macht den Ton nicht besser, nur die Hand müde.

## Ausprobieren
Spiel auf der A-Saite die Bünde 2, 3, 4, 5 mit den Fingern 1, 2, 3, 4.
::: try root=A steps="2 3 4 5" string=A

## Üben
::: variant for=fretted
Die Fingerübung 1-2-3-4 ab dem fünften Bund, langsam.
::: practice bundled=50 speeds="60 80 100"
:::

## Prüfen
