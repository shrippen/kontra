# Greifen ohne Kraft
id: greifen
for: e-bass
needs: bass-teile
terms: bund

## Vier Finger, vier Töne
Die Greifhand steht so, dass jeder Finger einen eigenen Ton hat, je einen Halbton auseinander: Zeigefinger 1,
Mittelfinger 2, Ringfinger 3, kleiner Finger 4. Der Daumen liegt hinter dem Hals, etwa hinter dem Mittelfinger.
::: figure root=A steps="2 3 4 5" labels="1 2 3 4" string=A
::: variant for=fretted
Ein Finger pro [[bund|Bund]]. Die Fingerkuppe drückt direkt hinter dem Bund, nicht darauf und nicht in der Mitte
zwischen zwei Bünden.
:::
::: variant for=fretless
Ohne Bünde greifst du genau auf der Linie, wo beim Bundbass der Bund wäre; dein Ohr entscheidet, ob der Ton stimmt.
:::

## Nur so fest wie nötig
Drück nur so fest, dass der Ton sauber klingt. Probier es aus: erst ganz leicht (es schnarrt), dann etwas fester, bis
der Ton klar ist. Mehr Kraft macht den Ton nicht besser, nur die Hand müde.

## Ausprobieren
Spiel auf der A-Saite die vier Töne aus dem Bild mit den Fingern 1, 2, 3, 4.
::: try root=A steps="2 3 4 5" string=A

## Üben
Die Fingerübung 1-2-3-4, langsam.
::: practice bundled=50 speeds="60 80 100"

## Prüfen
::: variant for=fretted
::: question
Wo drückt die Fingerkuppe auf einem Bass mit Bünden?
- [ ] Genau auf dem Bund.
- [x] Direkt hinter dem Bund.
- [ ] In der Mitte zwischen zwei Bünden.
:::
:::
::: variant for=fretless
::: question
Wo greifst du auf einem Bass ohne Bünde?
- [ ] Irgendwo zwischen zwei Markierungen.
- [x] Genau auf der Linie, wo der Bund wäre.
- [ ] Kurz vor der Linie, wie hinter einem Bund.
:::
:::
