# Fretting without force
id: greifen
for: strings
needs: bass-teile
terms: bund

## One finger per fret
Place the fretting hand so that each finger has its own fret: index 1, middle 2, ring 3, little finger 4. The thumb
sits behind the neck, roughly behind the middle finger.
::: figure root=A steps="2 3 4 5" labels="1 2 3 4" string=A
::: variant for=fretted
The fingertip presses right behind the [[bund|fret]], not on it and not halfway between two frets.
:::
::: variant for=fretless
Without frets you press exactly on the line where the fret would be; your ear decides whether the note is in tune.
:::

## Only as hard as needed
Press only hard enough for a clean note. Try it: very lightly first (it buzzes), then a little harder until the note is
clear. More force does not make the note better, only the hand tired.

## Try it
On the A string, play frets 2, 3, 4, 5 with fingers 1, 2, 3, 4.
::: try root=A steps="2 3 4 5" string=A

## Practise
::: variant for=fretted
The 1-2-3-4 finger exercise from the fifth fret, slowly.
::: practice bundled=50 speeds="60 80 100"
:::

## Check
::: question
Where does the fingertip press on a fretted bass?
- [ ] Right on the fret.
- [x] Right behind the fret.
- [ ] Halfway between two frets.
:::
