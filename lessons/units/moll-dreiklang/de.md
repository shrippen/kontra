# Moll-Dreiklänge
id: moll-dreiklang
for: any
needs: moll-tonleiter dreiklang

## Grundton, kleine Terz, Quinte
Der Moll-Dreiklang unterscheidet sich vom Dur-Dreiklang in einem Ton: Die Terz liegt einen Halbton tiefer.
::: listen root=A steps="0 4 7"
::: listen root=A steps="0 3 7"
::: figure root=A steps="0 3 7 12" labels="1 b3 5 8"

## Ausprobieren
Spiel A-Moll als Arpeggio: A, C, E und das hohe A.
::: try root=A steps="0 3 7 12"

## Üben
Dreiklänge über eine Moll-Kadenz in A-Moll.
::: practice bundled=58 speeds="60 80 100"

## Prüfen
::: question
Welcher Ton macht aus A-Dur A-Moll?
- [ ] E wird zu E♭
- [x] C♯ wird zu C
- [ ] A wird zu A♭
:::
