# Fingerfolgen
id: fingerfolgen
for: e-bass
needs: greifen saitenwechsel
terms: fingersatz

## Jeder Finger arbeitet
Fingerfolgen trainieren alle vier Finger der Greifhand, auch den kleinen. Der [[fingersatz|Fingersatz]] 1-2-3-4 heißt:
Zeigefinger, Mittelfinger, Ringfinger, kleiner Finger, je ein Ton weiter, auf jeder Saite gleich.
::: figure root=A steps="2 3 4 5" labels="1 2 3 4" string=A

## Langsam ist schnell
Spiel so langsam, dass jeder Ton sauber klingt und die Finger nah an den Saiten bleiben. Tempo kommt von allein,
Verkrampfen nicht wieder weg.
::: hint
Tut etwas weh, Pause. Locker bleiben ist wichtiger als durchhalten.
:::

## Üben
Erst 1-2-3-4, dann 1-3-2-4.
