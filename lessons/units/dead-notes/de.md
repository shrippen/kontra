## Ein Klick statt eines Tons
Bei einer [[dead-note|Dead Note]] liegt die Greifhand locker auf der Saite, ohne sie herunterzudrücken. Der Anschlag
ergibt einen perkussiven Klick ohne Tonhöhe. Im Tab steht dafür ein x.
::: hint
Die Greifhand berührt die Saite nur. Drückst du zu fest, klingt doch ein Ton.
:::

## Üben
Dead Notes auf einem Akkord in A. Kontra bewertet hier den Zeitpunkt; der Klick hat keinen Ton.
::: practice bundled=61 speeds="60 80 100"

## Prüfen
::: question
Wie steht eine Dead Note im Tab?
- [ ] als 0
- [x] als x
- [ ] in Klammern
:::
