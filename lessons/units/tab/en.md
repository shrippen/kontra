## Lines are strings
A [[tab|tablature]] (tab for short) shows where you press, not which note it is. Each line is a string, the lowest at
the bottom. The number on the line says where you press; 0 is the [[leersaite|open string]].
::: figure root=E steps="0 3 5" labels="0 3 5" string=E
::: variant for=fretted
The number is the [[bund|fret]]: 3 means press behind the third fret.
:::

## Left to right
You read the numbers left to right, like text. Two numbers above each other sound together. How long a note lasts a
tab alone often does not show; for that Kontra has the lane and the notation.

## Try it
On the E string, play 0, 3, 5.
::: try root=E steps="0 3 5" string=E

## Check
::: question
What does the 0 on the bottom line mean?
- [x] Pluck the lowest string open.

:::
