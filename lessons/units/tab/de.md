## Linien sind Saiten
Eine [[tab|Tabulatur]] (kurz Tab) zeigt, wo du greifst, nicht welcher Ton es ist. Jede Linie ist eine Saite, die
tiefste unten. Die Zahl auf der Linie sagt, wo du greifst; 0 ist die [[leersaite|leere Saite]].
::: figure root=E steps="0 3 5" labels="0 3 5" string=E
::: variant for=fretted
Die Zahl ist der [[bund|Bund]]: 3 heißt hinter dem dritten Bund greifen.
:::

## Von links nach rechts
Du liest die Zahlen von links nach rechts, wie Text. Stehen zwei Zahlen übereinander, klingen sie gleichzeitig. Wie
lange ein Ton dauert, zeigt ein Tab allein oft nicht; dafür gibt es in Kontra die Lane und die Noten.

## Ausprobieren
Spiel auf der E-Saite 0, 3, 5.
::: try root=E steps="0 3 5" string=E

## Prüfen
::: question
Was bedeutet die 0 auf der untersten Linie?
- [x] Die tiefste Saite leer anschlagen.
- [ ] Nicht spielen.
- [ ] Die höchste Saite leer anschlagen.
:::
